# 项目目录结构说明

**项目：** 基于多模态交互的社区老年认知障碍早期筛查与干预系统  
**当前口径：** 以 2026-04-29 工作区代码为准

## 后端模块说明

| 目录/文件 | 说明 |
| --- | --- |
| `backend/app/main.py` | 注册 FastAPI、CORS、路由和 `/health` |
| `backend/app/config.py` | 应用、数据库、Redis、Celery、MinIO、微信、AI 策略配置 |
| `backend/app/models/` | `users`、`assessment_sessions`、`intervention_plans` 等 ORM 表 |
| `backend/app/routers/` | 当前 API 路由，统一带 `/api/v1` 前缀 |
| `backend/app/services/ai_service.py` | 规则/混合评估分析入口 |
| `backend/app/services/deep_model_service.py` | 深度多模态模型加载与推理 |
| `backend/app/services/rag_service.py` | RAG 知识索引与检索 |
| `backend/app/tasks/analysis.py` | 评估完成后的异步分析任务 |
| `backend/scripts/train_deep_multimodal.py` | 深度融合模型训练脚本 |

当前没有独立 `ai-engine/` 服务目录。规划中的 ASR、视觉、眼动等高级能力可作为后续服务拆分方向，但当前工程运行不依赖该目录。

## 命名规范

| 模块 | 规范 |
| --- | --- |
| Python 文件 | 小写下划线，如 `assessment_service.py` |
| Python 类 | 大驼峰，如 `AssessmentSession` |
| API 路径 | 小写短横线或资源复数，如 `/api/v1/assessments/sessions` |
| React 组件 | 大驼峰文件名，如 `CognitiveRadar.tsx` |
| 小程序页面 | 与 `pages.json` 路由一致 |
