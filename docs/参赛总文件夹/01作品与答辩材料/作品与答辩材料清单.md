## 答辩重点

1. 社区老年认知障碍早筛存在覆盖率不足、依从性低、医生人力不足的问题。
2. MindGuard 用小程序降低老人使用门槛，用 Web 管理端提高医生管理效率。
3. 系统形成“评估-分析-报告-干预-打卡-预警-复评”的闭环。
4. AI 采用规则、深度模型和混合策略，保证演示稳定性与技术创新表达。
5. 项目已具备可部署、可演示、可持续扩展的工程基础。
