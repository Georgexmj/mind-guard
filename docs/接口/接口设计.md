# API 接口设计文档

**基础 URL：** `/api/v1`  
**认证方式：** Bearer Token（JWT）  
**当前口径：** 以 `backend/app/routers/*.py` 为准，修订日期 2026-04-29

## 通用规范

除登录接口外，业务接口需携带：

```http
Authorization: Bearer <access_token>
Content-Type: application/json
Accept: application/json
```

当前后端使用 FastAPI 原生响应模型，不再使用统一 `{code,message,data}` 包装。接口错误由 FastAPI 返回标准 HTTP 状态码与 `detail` 字段。

| 路由前缀 | 模块 | 说明 |
| --- | --- | --- |
| `/api/v1/auth` | 认证 | 登录并获取 JWT |
| `/api/v1/users` | 用户 | 用户列表、老人列表、家属绑定、微信绑定 |
| `/api/v1/assessments` | 评估 | 会话、题目、作答、上传、完成、报告、趋势、复评提醒 |
| `/api/v1/questions` | 题库 | 题目列表、导出、新增、更新、删除 |
| `/api/v1/communities` | 社区 | 社区列表与创建 |
| `/api/v1/dashboard` | 看板 | 统计、趋势、风险分布、高风险与工作队列 |
| `/api/v1/interventions` | 干预 | 推荐、计划、记录、打卡、依从性工单、提醒 |
| `/api/v1/notifications` | 通知 | 通知列表、未读数、已读 |
| `/api/v1/rag` | 知识库 | 知识条目、索引重建、搜索 |

## 认证

### POST `/auth/login`

请求：

```json
{
  "phone": "13800000001",
  "password": "admin123"
}
```

响应包含 `access_token`、`token_type` 与当前用户信息。测试账号见根目录 `README.md`。

| GET | `/assessments/sessions/{session_id}/result` | 获取评估结果 |

| GET | `/assessments/reports/doctor/batch` | 批量导出医生报告 |

- 当前没有独立 `/modality` 路由；音频上传位于评估会话下。
- 当前没有独立 `/reports` 路由；报告和趋势能力位于 `/assessments` 下。
- `complete` 返回 `202 Accepted`，分析结果由 Celery 写入，前端可查询任务状态或结果接口。

## 数据字典

### 用户角色

`elder`、`family`、`doctor`、`admin`

### 评估状态

`pending`、`in_progress`、`completed`、`failed`

### 题目领域

`memory`、`orientation`、`language`、`attention`、`visuospatial`、`executive`

### 题目类型

`choice`、`voice`、`drawing`、`scale`

### 风险等级

当前 ORM 枚举为 `normal`、`mild_risk`、`high_risk`。部分前端展示会转译为“正常/轻度风险/高风险”。
