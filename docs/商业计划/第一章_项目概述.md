# 第一章 项目概述

## 1.1 产业背景

### 1.1.1 人口老龄化国家战略背景

截至2023年末，我国60岁及以上老年人口达2.97亿，占总人口的21.1%，正式迈入"深度老龄化社会"。国家卫生健康委数据显示，我国现有认知症（痴呆）患者约1500万，其中阿尔茨海默病（AD）占60%以上；轻度认知障碍（MCI）患者超过3000万，而MCI向AD的年转化率高达10%~15%。

> **核心矛盾**：认知障碍早期（MCI阶段）可逆或可干预，但现有临床诊断率不足30%，绝大多数患者在出现明显症状时已进入中重度阶段，错过最佳干预窗口期。

### 1.1.2 政策环境

| 政策文件 | 发布年份 | 核心内容 |
|----------|----------|----------|
| 《"十四五"国家老龄事业发展和养老服务体系规划》 | 2022 | 推进老年认知障碍友好社区建设，建立认知障碍早期识别干预机制 |
| 《关于开展老年人认知障碍风险筛查试点工作的通知》 | 2023 | 在全国100个试点城市开展社区认知筛查 |
| 《新一代人工智能发展规划》 | 2017 | 支持AI在医疗健康领域的创新应用 |
| 《"互联网+医疗健康"发展意见》 | 2018 | 鼓励开发面向老年人的健康管理应用 |

政策红利明确，社区级认知障碍早筛是国家医养结合战略的重要组成部分，具备广阔的政府采购与公益推广空间。

### 1.1.3 市场规模

- **认知障碍诊疗市场**：2023年全球认知障碍市场规模约420亿美元，中国市场约580亿元，预计2028年突破1200亿元（CAGR≈15.7%）
- **数字健康筛查市场**：中国老年数字健康管理市场2023年规模约310亿元，筛查工具细分市场约45亿元
- **社区医疗服务市场**：全国社区卫生服务中心3.4万个，乡镇卫生院3.6万个，潜在采购主体超7万家

## 1.2 市场竞争环境

### 1.2.1 现有解决方案痛点

**传统纸笔量表筛查（MMSE/MoCA）**的核心问题：
- 依赖专业医生现场施测，人力成本高，无法规模化
- 主观评分差异大，量表本身存在教育偏倚
- 无法捕捉细微的认知衰退信号（早期MCI极易漏诊）
- 无法提供纵向追踪，患者一次筛查后缺乏随访机制

**现有数字化产品对比**：

| 产品类型 | 代表产品 | 缺陷 |
|----------|----------|------|
| 单一量表电子化 | 某医院内部APP | 仅数字化，无AI分析，无多模态 |
| 专业医疗设备 | 神经心理测验软件（CANTAB等） | 价格高昂（数十万元），需专业操作员 |
| 海外AI筛查 | Linus Health、Cogstate | 不支持中文方言，无本土化适配 |
| 国内早期探索 | 少数医院科研项目 | 研究性质，无法社区部署，无完整干预链 |

### 1.2.2 市场空白

目前**尚无产品**同时满足：①社区/家庭场景可用、②支持中文及方言、③多模态AI分析、④提供干预建议、⑤家属-医生协同闭环。本项目正是填补这一空白。

## 1.3 项目内容与名称

**项目名称**：基于多模态交互的社区老年认知障碍早期筛查与干预系统

**英文名称**：MindGuard — Community Multimodal Cognitive Screening & Intervention System

**项目定义**：一套面向社区老年群体的认知障碍智能化早筛与干预平台，通过采集语音、面部表情、手写绘图、行为交互等多维度数据，利用跨模态注意力融合AI模型实现精准分级诊断（正常/MCI/轻度AD），并向老年用户、家属、社区医生提供差异化的健康管理与干预方案。

**核心载体**：
- **微信小程序**（老年端）——零安装门槛，一键启动评估
- **Web管理平台**（医生/管理员端）——评估结果审阅、预警管理、报告下载
- **FastAPI后端服务**——可私有化部署于社区卫生服务中心服务器

## 1.4 项目独创性与领先性

### 1.4.1 六大核心创新点

**创新一：跨模态注意力融合诊断模型（技术核心）**

首创将语音声学特征、面部微表情序列、手写时钟绘图评分、行为反应时序四类异构模态通过**Cross-Modal Attention Transformer**统一融合，相比单模态方法，MCI识别AUC提升约12%（内测数据）。

```
传统单模态量表          本项目多模态融合
量表得分 ─────────→   语音特征 ┐
                        面部特征 ├→ Cross-Modal → 分级诊断 + SHAP解释
                        手写特征 ┤    Attention
                        行为特征 ┘
```

**创新二：三级分类 + 纵向风险预测**

- 阶段一：LightGBM快速筛查（正常/异常，≤2分钟）
- 阶段二：多模态Transformer精细分级（NC/MCI/轻度AD）
- 阶段三：LSTM纵向模型预测12个月内MCI→AD转化概率

**创新三：AI可解释性（SHAP）**

每份报告附带SHAP瀑布图，明确指出"记忆力-定向力-语言流利度"哪个认知域是主要风险因子，医生可据此精准干预，避免"黑盒"诊断的信任危机。

**创新四：自适应评估（IRT/CAT）**

基于项目反应理论（IRT）动态选题，高能力受试者跳过简单题，低能力受试者避免因连续失败产生挫败感。平均题目数从30题压缩至18题，完成率提升35%。

**创新五：老年友好多模态交互设计**

- 微信小程序：零安装、大字体（≥22px）、语音引导、一键呼叫家属
- 语音任务：支持普通话+常见方言（粤语、闽南话、四川话）
- 手写时钟：Canvas 2D触屏绘制，自动几何评分，无需纸笔
- 无障碍反馈：wx.vibrateShort()震动提示 + TTS语音播报

**创新六：社区协同干预闭环**

```
筛查 → AI诊断 → 风险分层 → 个性化干预方案 → 定期随访 → 趋势报告 → 医生复核
  ↑_______________________________________家属参与协同_________________________↑
```

### 1.4.2 技术领先性对比

| 评估维度 | 行业现状 | 本项目 |
|----------|----------|--------|
| 输入模态数量 | 1~2种 | 4种（语音+面部+手写+行为） |
| 分类粒度 | 正常/异常（二分类） | NC/MCI/轻度AD（三分类）+ 风险概率 |
| 纵向预测 | 无 | LSTM 12个月风险曲线 |
| 可解释性 | 无 | SHAP特征重要性分析 |
| 社区部署成本 | 专业设备数十万 | 纯软件，服务器成本约5000元/年 |
| 语言本土化 | 英文为主 | 全中文 + 方言优化 |

## 1.5 项目价值主张

**对老年用户**：足不出户，10分钟完成认知健康自查，获得通俗易懂的健康报告

**对家属**：实时接收高风险预警，掌握父母认知状态变化趋势，科学安排就医

**对社区医生**：AI辅助筛查替代繁琐纸笔量表，工作效率提升3倍，精准锁定高风险患者

**对社区/政府**：低成本完成大规模老年认知筛查，满足《老年认知障碍风险筛查》政策要求，形成辖区健康大数据
