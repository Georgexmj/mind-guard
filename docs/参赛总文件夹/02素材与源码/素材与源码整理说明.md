# 素材与源码整理说明

## 建议打包文件名

```text
作品编号待定-素材源码.zip
```

取得正式作品编号后，将“作品编号待定”替换为大赛系统编号。

## 建议包含

| 路径 | 说明 |
| --- | --- |
| `backend/` | FastAPI 后端、AI 服务、Celery 任务、训练脚本 |
| `web-admin/` | React 管理端源码 |
| `miniprogram/` | UniApp 微信小程序源码 |
| `data/` | 合成数据生成脚本、代表性数据样例、训练清单 |
| `nginx/` | Nginx 配置，提交前注意排除真实私钥 |
| `docker-compose.yml` | 一键部署编排 |
| `.env.example` | 环境变量示例 |
| `README.md`、`QUICKSTART.md` | 运行说明 |
| `docs/` | 必要设计与开发文档，可按大赛分类另放 PDF |

## 必须排除

| 路径/文件 | 原因 |
| --- | --- |
| `web-admin/node_modules/` | 第三方依赖，体积大，非团队源码 |
| `miniprogram/node_modules/` | 第三方依赖 |
| `backend/.venv/` | 本地虚拟环境 |
| `.git/` | Git 历史不属于提交源码 |
| `.env` | 可能包含真实密钥 |
| 数据库数据卷 | 体积大且不属于源码 |
| 真实证书私钥 `.key` | 安全风险 |

## 代表性素材建议

- `docs/微信小程序图标.png`
- 小程序二维码或预览码。
- Web 管理端关键页面截图。
- 老人端评估流程截图。
- 合成数据样例 CSV 的少量代表文件。
- 答辩 PPT 中使用的架构图、流程图。

## 打包后核对

- [ ] 压缩包能在另一台电脑解压。
- [ ] 不含真实 `.env`、证书私钥、数据库密码。
- [ ] 不含 `node_modules`、`.venv`。
- [ ] 总体体积小于 1GB，建议小于 500MB。
- [ ] 根据 `README.md` 和 `QUICKSTART.md` 可以重新安装依赖并运行。
