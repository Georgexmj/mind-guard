# 第五章 （营销）发展规划

## 5.1 产品定位与价格策略

### 5.1.1 产品定位

```
MindGuard 产品定位：
"让每一位中国老人都能享受到专业级认知健康早筛服务"

不是：昂贵的医疗设备 → 人人可负担
不是：娱乐性小游戏 → 有临床依据
不是：孤立的单次测试 → 长期健康管理
```

**差异化定位标签**：
- **专业**：AI算法经临床数据验证，SHAP可解释报告
- **易用**：微信小程序，老人10分钟自主完成
- **全程**：筛查-诊断-干预-随访完整闭环
- **低价**：比医院记忆门诊检查成本低90%

### 5.1.2 价格策略

**B端（机构）定价**

| 产品版本 | 目标客户 | 价格 | 包含功能 |
|----------|----------|------|----------|
| 基础版 | 社区卫生服务中心 | **8,800元/年** | 无限次评估、管理后台、数据导出报告 |
| 专业版 | 二级医院记忆门诊 | **28,800元/年** | 基础版+API对接HIS系统+私有化部署+技术支持 |
| 政府版 | 区县卫健委 | **定制报价** | 辖区大数据看板、批量管理、GIS热力图 |

**C端（家庭/个人）定价**

| 产品版本 | 价格 | 包含内容 |
|----------|------|----------|
| 单次评估 | **39元/次** | 完整评估+AI报告+SHAP解读 |
| 家庭月卡 | **99元/月** | 1位老人无限次评估+月度趋势报告+家属推送 |
| 家庭年卡 | **599元/年**（折合50元/月）| 月卡全部内容+年度健康分析+医生在线问答券×2 |

**竞品价格参考**：
- 医院记忆门诊挂号+量表评估：约300~600元/次
- Cogstate国际版：约$150/次
- 本系统单次价格约为医院的1/10，具备极强价格优势

## 5.2 渠道建设

### 5.2.1 B端渠道策略

**渠道一：政府/卫健委渠道（优先级最高）**

路径：
```
参加大赛获奖 → 媒体报道 → 地方卫健委关注
                              ↓
                      联系试点社区
                              ↓
                      免费试用3个月
                              ↓
                      付费续费/扩大推广
```

切入点：
- 响应《老年认知障碍风险筛查试点》政策，主动对接100个试点城市
- 向民政局/卫健委提交"政采云"挂网申请
- 参与政府采购招标（软件类，单价<50万无需招标）

**渠道二：医疗机构直销**

- 目标：二三线城市二级医院神经内科/老年科（约800家，一线竞争压力小）
- 方式：学术会议（中国老年学学会年会）展示 + 科室主任推荐
- 关键：提供免费3个月试用，用数据说话

**渠道三：养老机构渠道**

- 全国养老机构约4万家，入住老人认知评估有刚需
- 渗透方式：联系省级养老协会，在会员机构批量推广

### 5.2.2 C端渠道策略

**核心渠道：微信生态裂变**

```
老人完成评估 → 报告生成 → 一键分享给子女（带邀请码）
    ↑                                ↓
    └──── 子女查看报告后 ←── 子女为父母付费订阅
                    产生"关心父母"的社交转发
```

裂变激励设计：
- 分享评估报告给家人：双方各获1次免费评估
- 邀请好友注册：获得30天家庭月卡
- 社区群分享：群内3人注册享7折优惠

**内容营销（公众号/小红书/抖音）**

| 平台 | 内容类型 | 目标 |
|------|----------|------|
| 微信公众号 | 认知健康科普文章（每周2篇）| 搜索引流，树立专业形象 |
| 小红书 | 老年认知科普、子女关爱父母故事 | 45~55岁女性子女群体 |
| 抖音 | 短视频：如何发现父母认知异常 | 广泛曝光，品牌认知 |
| 微信视频号 | 直播答疑：如何读懂认知评估报告 | 转化付费用户 |

**线下活动**

- 在合作社区举办"认知健康免费筛查日"（每季度1次）
- 在老年大学、社区活动中心设置扫码体验站
- 联合社区志愿者进行一对一辅导使用

## 5.3 推广策略

### 5.3.1 冷启动期（0~6个月）：口碑与信任建设

**策略核心**：先免费，积累用户，获取真实数据反馈

行动项：
1. 在3~5个社区提供完全免费服务（换取数据采集授权）
2. 撰写论文投稿（中华老年医学杂志/计算机学报），提升学术背书
3. 参加全国大学生软件创新大赛（当前目标），获奖后大规模传播
4. 申请大学生创业孵化项目，获得媒体曝光

**KPI**：
- 注册用户：500人
- 完成评估次数：1000次
- 合作机构：2家（试用）

### 5.3.2 成长期（6~18个月）：规模化获客

**策略核心**：B端签约机构，C端裂变增长

行动项：
1. B端：拜访20个目标城市的社区卫生服务中心，争取10家签约
2. C端：公众号粉丝10万+，小红书月曝光100万+
3. 推出"子女礼物"营销：父亲节/母亲节期间推送"为父母做认知体检"
4. 获得1~2家知名医院的合作背书并展示在产品中

**KPI**：
- 注册用户：5万人
- 付费用户：2000人（C端）
- 机构签约：15家
- 月收入：>20万元

### 5.3.3 成熟期（18~36个月）：品牌与生态

**策略核心**：成为社区认知筛查标准工具，进入政府采购名录

行动项：
1. 进入国家卫健委"推荐健康管理工具"目录
2. 与保险公司合作：健康险增值服务，批量采购
3. 开放API平台：接入其他养老应用（如乐龄、康复通等）
4. 建立认知健康研究院（品牌升级，与高校联合）

**KPI**：
- 注册用户：50万人
- 机构签约：100家+
- ARR：500万元+

## 5.4 公司发展规划（1~3年）

| 阶段 | 目标 | 关键行动 |
|------|------|----------|
| Q1 2026 | 竞赛获奖 + MVP上线 | 完成全端开发，参加大赛，争取一等奖 |
| Q2 2026 | 种子用户积累 | 免费开放，3~5个社区试点，收集反馈 |

- 团队从6人扩展至12人（招募1名销售、1名市场、1名后端）

- 机构签约20家，月收入>15万元

- 融资A轮（目标500万~1000万元）

- 产品矩阵扩展：增加"轻度认知障碍康复训练"模块（增值服务）
- 申请三类医疗器械注册证（如产品规模达到准入门槛）
