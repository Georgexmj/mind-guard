# AI 工具使用说明草稿

> 本项目研发、文档梳理和参赛材料整理过程中涉及 AI 辅助，建议按大赛官方“4-AI工具使用说明（选用模板）（2026年版）”提交 PDF 版本和佐证附件。

## 1. 使用 AI 工具的范围

| 阶段 | AI 辅助内容 | 人工审核方式 |
| --- | --- | --- |
| 需求整理 | 辅助梳理老人、医生、家属、管理员四类角色需求 | 团队结合项目目标人工确认 |
| 架构设计 | 辅助形成后端、Web、小程序、部署架构描述 | 对照实际代码和配置修订 |
| 代码实现 | 辅助生成或修改部分业务逻辑、页面样式、接口调用 | 团队运行、调试并人工合并 |
| 文档撰写 | 辅助生成 README、接口、部署、参赛材料草稿 | 对照项目代码、比赛要求人工校对 |
| 参赛材料 | 辅助整理 PPT 大纲、视频脚本、提交清单 | 团队最终编辑和确认 |

## 2. 未使用 AI 替代的内容

- 项目选题、参赛方向和最终提交决策由团队确定。
- 核心功能是否可运行由团队本地运行和人工验证。
- 竞赛材料最终版本由团队按官方模板排版和导出。
- 用户隐私、密钥、真实个人数据不输入 AI 工具。

## 3. AI 工具使用原则

1. AI 输出只作为草稿或辅助建议，不直接等同最终作品。
2. 涉及代码修改时，由团队阅读差异、运行验证后保留。
3. 涉及医学健康表述时，避免将系统描述为临床诊断工具，仅作为早筛和随访辅助。
4. 涉及第三方素材时，明确来源和授权，不使用无法确认版权的素材。
5. 涉及比赛要求时，以官方模板和通知为准。

## 4. 佐证材料建议

可准备以下附件：

- AI 辅助生成文档草稿的对话截图或记录摘要。
- AI 辅助代码修改的 Git diff 截图。
- 人工审核修改记录。
- 最终文档与代码运行截图。
