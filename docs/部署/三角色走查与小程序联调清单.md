## 3. 页面级走查口径（建议按此验收）

### 3.1 管理员（Web 管理端）

- 登录后默认进入：`/dashboard`
- 应可见菜单：仪表盘、老人管理、评估管理、干预管理、题库管理、通知中心
- 关键能力：
  - 题库增删改查（已实现）
  - 干预计划创建/编辑
  - 查看全部会话与统计看板

### 3.2 医生（Web 管理端）

- 登录后默认进入：`/dashboard`
- 应可见菜单：与管理员接近
- 关键差异：
  - 题库仅查看，不能新增/编辑/删除
  - 可管理干预计划
  - 可查看全部评估会话

### 3.3 老人（小程序端为主）

- 建议入口：微信小程序（不是 Web 管理端）
- 小程序已实现：
  - 老人登录（非老人角色会被拦截并登出）
  - 开始评估 -> 作答（选择/量表/语音/绘图）-> 完成 -> 结果页
  - 历史结果查看

## 4. 小程序联调前置清单

- 后端容器正常：`mindguard-backend-1` healthy，`mindguard-celery_worker-1` running
- 小程序 API 基地址已配置为可达地址（推荐 HTTPS）
- 微信公众平台已配置 `request 合法域名`
- Redis、MySQL 可用（异步分析依赖）

## 5. 小程序端联调步骤（打勾式）

1. 打开微信开发者工具，导入目录：`miniprogram/dist/build/mp-weixin`
2. 设置 API 基地址（控制台）：
   - `wx.setStorageSync('mindguard_api_base_url', 'https://你的域名/api/v1')`
3. 老人账号登录：`13800000003 / elder123`
4. 点击“开始评估”，确认成功创建会话并拉取题目
5. 完成至少 1 道选择题、1 道语音题、1 道绘图题、1 道量表题
6. 提交完成后进入结果页，出现风险等级、MMSE、分域得分
7. 进入“我的”页，可看到历史记录
8. 用医生/管理员账号登录小程序，确认被拦截并提示使用 Web 管理端

## 6. 一次性排障建议

- 如果结果页一直“分析中”：
  - 查 `celery_worker` 日志
  - 查 `backend` 日志
  - 查 Redis 连通
- 如果小程序请求失败：
  - 先检查合法域名和 HTTPS 证书
  - 再检查 `mindguard_api_base_url`
- 如果 Web 端 30000 打不开：
  - 本机端口冲突时使用 `31000`
