## 4. 方式一：Docker Compose 一键部署（推荐）

适用于：**竞赛演示、快速验证、测试环境**

### 4.1 克隆项目

```bash
git clone <仓库地址>
cd 基于多模态交互的社区老年认知障碍早期筛查与干预系统
```

### 4.2 首次启动

```bash
cd infrastructure

# 后台启动所有服务（首次构建镜像约 3~5 分钟）
docker compose up -d
```

### 4.3 检查服务状态

```bash
# 查看各容器运行状态（均应为 healthy 或 running）
docker compose ps

# 实时查看后端日志（等待 "Application startup complete"）
docker compose logs -f backend

# 查看 Celery Worker 日志
docker compose logs -f celery_worker
```

预期输出（后端）：
```
cognitive_backend  | INFO: Application startup complete.
cognitive_backend  | INFO: Uvicorn running on http://0.0.0.0:8000
```

### 4.4 访问验证

| 服务 | 地址 | 账号/密码 |
|------|------|-----------|
| Web 管理端 | http://localhost:30000 | 见演示账号章节 |
| API 文档 | http://localhost:30001/docs | — |
| MinIO 控制台 | http://localhost:30005 | cognitive_admin / cognitive_minio_2026 |

### 4.5 停止与重置

```bash
# 停止所有服务（保留数据）
docker compose down

# 完全清除数据重新初始化
docker compose down -v
docker compose up -d
```

## 5. 方式二：本地开发部署

适用于：**功能开发、调试、代码修改**

### 步骤 1：启动基础设施（仅数据库等）

```bash
cd infrastructure
docker compose up -d mysql redis minio influxdb mongodb
```

等待约 20 秒，直到 MySQL 完全就绪：

```bash
docker compose logs mysql | tail -5
# 看到 "ready for connections on port 3306" 即可继续
```

### 步骤 2：后端环境配置

```bash
cd backend

# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

创建 `.env` 文件（或直接使用默认值，见第 8 章）：

```bash
# backend/.env
DATABASE_URL=mysql+pymysql://cognitive_user:cognitive_pass_2026@localhost:30002/cognitive_db
REDIS_URL=redis://localhost:30003/0
CELERY_BROKER_URL=redis://localhost:30003/1
CELERY_RESULT_BACKEND=redis://localhost:30003/2
MINIO_ENDPOINT=localhost:30004
MINIO_ACCESS_KEY=cognitive_admin
MINIO_SECRET_KEY=cognitive_minio_2026
MINIO_SECURE=false
SECRET_KEY=cognitive-secret-key-change-in-production-2026
DEBUG=true
```

### 步骤 3：初始化数据库

```bash
# 建表 + 写入种子数据（管理员/医生/老人账号 + 20道题）
python -m app.initial_data
```

成功输出：
```
✓ 数据库表创建完成
✓ 社区：幸福社区（张家界市）
✓ 管理员账号创建：13800000001
✓ 医生账号创建：13800000002
✓ 老人账号创建：13800000003
✓ 题库初始化：20道题
初始化完成！
```

### 步骤 4：启动后端

```bash
uvicorn app.main:app --reload --port 8000
```

访问 http://localhost:8000/docs 验证。

### 步骤 5：启动 Celery Worker

新开终端，激活同一虚拟环境：

```bash
cd backend
source .venv/bin/activate  # 或 Windows: .venv\Scripts\activate
celery -A app.tasks.celery_app worker --loglevel=info --concurrency=2
```

### 步骤 6：启动 Web Admin

```bash
cd web-admin
npm install
npm run dev
```

访问 http://localhost:5173

### 步骤 7：启动小程序

1. 打开**微信开发者工具**
2. 新建项目 → 导入 → 选择 `miniprogram/` 目录
3. AppID 填写小程序 AppID（演示可选"测试号"）
4. 修改 `miniprogram/utils/request.js` 中的 `BASE_URL`：

   ```js
   const BASE_URL = 'http://localhost:8000/api/v1'
   ```

5. 工具栏 → 详情 → 本地设置 → 勾选 **"不校验合法域名"**
6. 编译运行

## 6. 方式三：生产服务器部署

适用于：**真实运营环境**

### 6.1 服务器推荐配置

| 规格 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 4 核 | 8 核 |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 50 GB SSD | 100 GB SSD |
| 带宽 | 5 Mbps | 10 Mbps |
| 操作系统 | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### 6.2 安装 Docker

```bash
# Ubuntu 22.04
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
newgrp docker

# 验证
docker --version
docker compose version
```

### 6.3 修改生产环境配置

在 `infrastructure/` 下创建 `docker-compose.prod.yml`，覆盖关键配置：

```yaml
# infrastructure/docker-compose.prod.yml
services:
  backend:
    environment:
      SECRET_KEY: <使用openssl rand -hex 32生成的随机密钥>
      DEBUG: "false"
      DATABASE_URL: mysql+pymysql://cognitive_user:<强密码>@mysql:3306/cognitive_db
      ALLOWED_ORIGINS: "https://your-domain.com"
    # 生产环境去掉热重载
    command: >
      sh -c "sleep 5 && python -m app.initial_data && uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4"

  mysql:
    environment:
      MYSQL_ROOT_PASSWORD: <强密码>
      MYSQL_PASSWORD: <强密码>
    # 生产环境不暴露端口到主机
    ports: !reset []

  redis:
    ports: !reset []

  mongodb:
    ports: !reset []
```

### 6.4 部署命令

```bash
cd infrastructure

# 使用生产配置启动
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d

# 查看状态
docker compose ps
```

### 6.5 配置 Nginx 反向代理（推荐）

```nginx
# /etc/nginx/conf.d/mindguard.conf
server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate /etc/ssl/certs/your-domain.crt;
    ssl_certificate_key /etc/ssl/private/your-domain.key;

    # Web Admin
    location / {
        proxy_pass http://127.0.0.1:30000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # API
    location /api/ {
        proxy_pass http://127.0.0.1:30001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        # 文件上传大小限制
        client_max_body_size 50M;
    }
}

# HTTP 重定向到 HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$host$request_uri;
}
```

### 6.6 生成 SECRET_KEY

```bash
openssl rand -hex 32
# 示例输出：a3f8c2e1d4b7f9a0c5e2b1d8f3a6c9e0d2b5f8a1c4e7b0d3f6a9c2e5b8d1f4a7
```

## 7. 微信小程序发布

### 开发测试阶段

1. 使用微信开发者工具导入 `miniprogram/` 目录
2. 在"本地设置"中勾选"不校验合法域名"
3. `request.js` 中 `BASE_URL` 填本地或测试服务器地址

### 正式发布阶段

1. **域名备案**：确保 API 域名已完成 ICP 备案
2. **HTTPS 必须**：微信小程序正式版只允许 HTTPS 请求
3. **合法域名配置**：
   - 登录 [微信公众平台](https://mp.weixin.qq.com)
   - 开发 → 开发设置 → 服务器域名
   - 将 API 域名添加到 `request 合法域名` 和 `uploadFile 合法域名`
4. **更新 BASE_URL**：

   ```js
   // miniprogram/utils/request.js
   const BASE_URL = 'https://api.your-domain.com/api/v1'
   ```

5. **上传代码**：微信开发者工具 → 上传 → 提交审核 → 发布

## 13. 常见问题排查

### Q1：docker compose up 报端口冲突

```bash
# Windows — 查找占用 30002 端口的进程
netstat -ano | findstr 30002
taskkill /PID <PID> /F

# macOS/Linux
lsof -i :30002
kill -9 <PID>
```

常见冲突端口及解决方式：

| 端口 | 服务 | 常见冲突原因 |
|------|------|------------|
| 30000 | web_admin | 其他本地 Web 服务 |
| 30002 | mysql | 本机已安装 MySQL |
| 30003 | redis | 本机已安装 Redis |
| 30001 | backend | 其他 Python 服务 |
| 30004 | minio | WSL 或其他服务 |

修改 `docker-compose.yml` 中对应服务的 `ports` 左边端口号即可（如 `"13306:3306"`），同时更新 `DATABASE_URL` 等环境变量。

---

### Q2：后端报 "Can't connect to MySQL server"

```bash
# 检查 MySQL 是否完全启动
docker compose logs mysql | grep "ready for connections"

# 手动等待并重试
sleep 20 && docker compose restart backend
```

---

### Q3：小程序报 "request:fail url not in domain list"

- **开发调试**：微信开发者工具 → 详情 → 本地设置 → 勾选"不校验合法域名"
- **正式版本**：将 `https://api.your-domain.com` 添加到小程序后台合法域名

---

### Q4：AI 分析一直显示"分析中"不结束

```bash
# 检查 Celery Worker 是否运行
docker compose ps celery_worker

# 查看 Worker 日志
docker compose logs --tail=50 celery_worker

# 检查 Redis 连接
docker compose exec redis redis-cli ping   # 应返回 PONG
```

```bash
# 检查容器是否正常运行
```

### Q6：MinIO 文件上传失败

```bash
# 确认 MinIO 服务正常
```
