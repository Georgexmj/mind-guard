# 微信小程序老人端部署指南（MindGuard）

本文档用于部署 `miniprogram` 老人自评端，并与后端接口联通。

## 1. 功能范围

当前微信小程序端定位为“老人自我评估端”，支持：

- 老人账号登录（仅支持 `elder/elderly` 角色）
- 认知评估流程（选择题、量表题、语音题、时钟绘图题）
- 评估结果查看与历史记录查看

说明：管理员、医生账号请使用 Web 管理端，不在该小程序开放范围内。

## 2. 环境准备

- Node.js 18+（建议 20 LTS）
- HBuilderX（推荐）或 UniApp CLI
- 微信开发者工具（最新版）
- 已可访问的后端服务地址（建议 HTTPS 域名）

## 3. 安装依赖

在项目根目录执行：

```bash
cd miniprogram
npm install
```

## 4. 配置后端 API 地址

小程序请求地址来源顺序：

1. 本地存储 `mindguard_api_base_url`
2. 环境变量 `UNI_API_BASE_URL` / `VITE_API_BASE_URL`
3. 默认值 `http://127.0.0.1:8000/api/v1`

生产环境建议使用 HTTPS，例如：`https://api.your-domain.com/api/v1`。

### 4.1 开发期（本地调试）

可在登录前通过控制台执行（微信开发者工具）：

```js
wx.setStorageSync('mindguard_api_base_url', 'http://你的局域网IP:8000/api/v1')
```

### 4.2 生产期（正式发布）

建议在构建环境注入：

```bash
UNI_API_BASE_URL=https://api.your-domain.com/api/v1
```

并在微信公众平台将该域名加入“request 合法域名”。

## 5. 启动与构建

### 5.1 开发模式

```bash
npm run dev:mp-weixin
```

### 5.2 生产构建

```bash
npm run build:mp-weixin
```

构建结果导入微信开发者工具，进行预览与上传。

## 6. 微信后台关键配置

- 在“小程序后台 -> 开发管理 -> 开发设置”配置：
- `request` 合法域名：后端 API 域名（必须 HTTPS）
- 如启用文件上传能力，需配置 `uploadFile` 合法域名

当前版本语音与绘图答案通过普通 JSON 接口提交（不依赖独立上传接口）。

## 7. 联通性检查清单

发布前建议按以下顺序自测：

1. 使用老人账号登录：`13800000003 / elder123`
2. 使用医生或管理员账号登录：应被拦截并提示使用 Web 管理端
3. 开始评估并完成至少 1 套题目
4. 结果页显示风险等级、MMSE 分数、分域评分
5. 首页与“我的”页面可查看历史记录

## 8. 常见问题

### 8.1 登录失败 / 网络失败

- 确认 `mindguard_api_base_url` 是否正确
- 确认后端服务可访问（浏览器打开 `/docs` 或 `/health`）
- 确认微信后台“合法域名”已配置

### 8.2 403 无权限

- 小程序老人端仅支持老人账号
- 医生、管理员账号请改用 Web 管理端

### 8.3 结果页一直分析中

- 检查后端 Celery Worker 是否启动
- 检查 Redis 连通性
- 查看后端日志 `docker compose logs -f backend celery_worker`

## 9. 推荐部署顺序

1. 先按 `docs/部署/Docker一键部署指南.md` 启动后端与 Web 管理端
2. 再按本文档部署微信小程序老人端
3. 完成账号登录、评估、结果回显的全链路验证后再发布
