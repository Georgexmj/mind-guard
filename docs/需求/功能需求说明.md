# 功能需求说明书

**项目：** 基于多模态交互的社区老年认知障碍早期筛查与干预系统
**版本：** v1.0 | 2026-03
**竞赛：** 全国大学生软件创新大赛

---

## 一、项目背景与目标

### 1.1 背景

中国60岁以上老年人口已超3亿，轻度认知障碍（MCI）患病率约15%，即约4500万人处于认知衰退的早期可干预阶段。然而，当前社区层面的认知筛查存在以下痛点：

- **覆盖率极低**：传统量表需要专业人员面对面施测，基层医疗资源严重不足
- **时机滞后**：大多数患者确诊时已进入中重度阶段，错过最佳干预时机
- **工具局限**：现有筛查工具（如MMSE）仅使用单一模态（纸笔问卷），受教育程度偏差大
- **干预缺位**：筛查与干预割裂，筛出高危老人后缺乏系统性的后续干预支持

### 1.2 目标

构建一套**面向社区的多模态认知障碍早期筛查与干预闭环系统**，实现：
1. 老年人可独立完成（或在最少辅助下完成）的多模态认知评估
2. AI驱动的精准风险分层与可解释诊断报告
3. 个性化干预方案推荐与执行跟踪
4. 社区医生的批量管理与预警响应

## 二、用户角色定义

### 角色1：老年用户（Elder）

**典型画像：** 65~85岁，可能有视力下降、手指精细度下降、受教育程度低（小学及以下）

**核心需求：**
- 能够独立完成认知评估（语音为主，减少打字）
- 评估过程有全程语音引导，不会"卡住"
- 结果用通俗语言解释（"记忆力正常"而非"认知域得分78.3"）
- 能看到简单的干预训练任务

**非功能需求：**
- 字体≥32px（可调）
- 操作步骤≤3步完成任何核心功能
- 响应延迟≤1秒（避免老人误以为"没按成功"而多次点击）

---

### 角色2：家属监护人（Family）

**典型画像：** 子女或配偶，35~60岁，通常不在老人身边

**核心需求：**
- 查看老人完整的评估报告和历史趋势
- 高危预警消息第一时间推送至手机
- 参与制定干预计划
- 了解老人的干预执行情况（是否按计划训练）

---

### 角色3：社区医生/护士（Doctor）

**典型画像：** 社区卫生服务站医护人员，管辖100~500名老年居民

**核心需求：**
- 管理辖区全部老年用户（健康档案、评估记录、干预计划）
- 社区层面的认知健康分布看板（高危人群识别）
- 为高危老人制定专业干预方案
- 辅助老人完成评估（协助操作模式）

---

### 角色4：系统管理员（Admin）

**核心需求：**
- 管理社区信息和用户账号
- 系统级配置（题库管理、干预库更新、阈值调整）
- 全平台数据统计和导出

## 三、功能需求详细说明

### 3.1 多模态数据采集模块

#### FR-01：语音评估任务
**描述：** 系统通过语音引导老人完成多种口语认知任务，录制语音并进行特征提取。

**功能点：**
- FR-01-1：图片描述任务（展示标准图片，老人用语音描述内容，60~120秒）
- FR-01-2：词语流利度测试（60秒内说出以指定字开头的词语）
- FR-01-3：句子复述任务（老人跟读并回忆复述）
- FR-01-4：延迟词语回忆（5分钟后语音回忆之前听到的词语）
- FR-01-5：系统对录音进行质量检测，噪音过大时提示重新录制（质量分<0.6）

**验收标准：**
- 语音上传成功率≥99%（网络正常情况）
- 语音识别（FunASR）汉语字准确率≥90%
- 质量检测误判率≤5%

---

#### FR-02：手写/绘图评估
**描述：** 在触屏设备上完成时钟绘图等视空间任务，采集笔迹坐标序列。

**功能点：**
- FR-02-1：时钟绘图测试（触屏绘制，采集坐标+时间戳+压感）
- FR-02-2：五边形临摹（MMSE标准图形临摹）
- FR-02-3：连线测试（数字1-A-2-B...交替连线）
- FR-02-4：实时绘制预览（老人能看到自己画的内容）
- FR-02-5：绘制完成后截图存储至MinIO

**验收标准：**
- 坐标采集频率≥60点/秒
- 图像存储分辨率≥512×512

---

#### FR-03：行为数据自动采集
**描述：** 在老人完成所有评估任务过程中，系统自动记录交互行为数据（无需老人主动配合）。

**功能点：**
- FR-03-1：记录每道题的开始时间、提交时间（毫秒精度）
- FR-03-2：记录触屏点击坐标和目标坐标（精准度分析）
- FR-03-3：记录答题修改次数
- FR-03-4：记录语音任务的停顿时间和位置

---

### 3.2 认知评估模块

#### FR-04：自适应评估流程
**描述：** 根据初步评估结果，动态决定评估深度。

**功能点：**
- FR-04-1：5分钟简版筛查（10道核心题，快速风险判断）
- FR-04-2：25分钟完整评估（数字化MMSE+MoCA全版题目）
- FR-04-3：IRT自适应选题（根据答题情况选择难度合适的下一题）
- FR-04-4：评估过程可暂停保存，30分钟内可续做（非重新开始）
- FR-04-5：TTS语音引导每一步操作（"请用语音说出图片中的物品名称"）

**验收标准：**
- 简版5分钟完成率≥85%（老年用户在辅助下）
- 题目加载时间≤500ms

---

#### FR-05：数字化量表实现
**描述：** 将传统MMSE（30分）和MoCA（30分）数字化，保留原始评分同时新增多模态采集。

**功能点：**
- FR-05-1：MMSE 11个子项完全数字化（定向力/记忆/注意力/语言/图形）
- FR-05-2：MoCA 8个子项数字化（交替连线/视空间/命名/注意/语言/抽象/记忆/定向）
- FR-05-3：受教育年限校正（文盲老人MoCA分数+1，与原量表规范一致）
- FR-05-4：系统自动计算MMSE/MoCA总分并分档（正常/可疑/认知障碍）

---

### 3.3 AI智能分析模块

#### FR-06：多模态AI诊断
**描述：** 整合四种模态数据，输出认知状态分类和风险概率。

**功能点：**
- FR-06-1：异步执行AI分析（评估完成后提交Celery任务）
- FR-06-2：三分类输出：NC（认知正常）/ MCI（轻度认知障碍）/ mild_AD
- FR-06-3：置信度输出（<0.60时报告标注"结果参考性有限，建议专科就诊"）
- FR-06-4：六维认知域得分（0~100分，与同龄正常人对比）
- FR-06-5：SHAP可解释性输出（各模态特征贡献度百分比）
- FR-06-6：数据质量不足时（某模态质量分<0.6）标注说明，使用可用模态结果

**验收标准：**
- AI分析总耗时≤30秒（P95）
- 三分类F1-macro≥0.78（在验证集上）

---

#### FR-07：纵向风险预测
**描述：** 对有多次评估记录的用户，预测认知衰退趋势和未来转化风险。

**功能点：**
- FR-07-1：用户累计≥2次评估后自动激活纵向预测
- FR-07-2：输出12个月内MCI→AD转化概率（低/中/高/极高风险）
- FR-07-3：认知衰退速率估算（分/月）
- FR-07-4：在报告中展示趋势折线图

---

### 3.4 干预管理模块

#### FR-08：个性化干预推荐
**描述：** 基于评估结果自动推荐个性化干预方案。

**功能点：**
- FR-08-1：评估完成后自动生成Top-5干预推荐
- FR-08-2：推荐基于薄弱认知域（得分最低的域优先）
- FR-08-3：推荐结果附带循证支持说明（"该方法已在N名相似老人中验证有效"）
- FR-08-4：医生可接受/修改/拒绝推荐方案
- FR-08-5：家属可查看并参与制定干预计划

**干预类型库（最小化可行产品需包含）：**

| 类型 | 至少包含内容 |
|------|------------|
| 认知训练 | 词语联想、数字记忆、图片配对游戏 |
| 运动干预 | 太极拳分解动作视频 |
| 音乐治疗 | 老歌填词、节奏跟拍 |
| 社交活动 | 视频通话提醒、社区活动通知 |
| 生活方式 | 饮食建议清单、睡眠记录提醒 |

---

#### FR-09：干预执行追踪
**描述：** 追踪干预计划的执行情况，评估干预效果。

**功能点：**
- FR-09-1：老人完成训练后可记录执行（时长、完成度）
- FR-09-2：家属可查看老人每日执行记录
- FR-09-3：医生可查看辖区内所有老人干预完成率报表
- FR-09-4：干预效果分析：对比干预前后认知评分变化

---

### 3.5 报告与可视化模块

#### FR-10：个人评估报告
**描述：** 生成多层次的评估报告（面向不同角色，详简程度不同）。

**功能点：**
- FR-10-1：老年版报告（简化文字说明，字大，无专业术语）
- FR-10-2：家属版报告（详细结果 + 趋势 + 干预建议）
- FR-10-3：医生版报告（全量数据 + SHAP解释 + 模态质量）
- FR-10-4：认知雷达图（6维，与同龄参考人群对比）
- FR-10-5：PDF导出功能
- FR-10-6：自然语言解读（将专业指标转化为通俗说明）

---

#### FR-11：社区管理看板
**描述：** 面向社区医生的数据驾驶舱。

**功能点：**
- FR-11-1：辖区认知状态分布（正常/MCI/AD比例）
- FR-11-2：高危老人预警列表（风险等级≥high，按风险排序）
- FR-11-3：筛查覆盖率追踪（已评估/总注册人数）
- FR-11-4：月度趋势图（评估人数、平均分、高危人数）
- FR-11-5：地理分布热力图（可选，有坐标数据时展示）

---

### 3.6 用户账号管理模块

#### FR-12：多种登录方式
- FR-12-1：手机号+短信验证码（主要方式）
- FR-12-2：人脸识别登录（老年用户首选，首次使用需录入人脸）
- FR-12-3：声纹识别登录（可选，与人脸识别二选一）

#### FR-13：角色与权限管理
- FR-13-1：RBAC权限控制（四种角色权限分离）
- FR-13-2：家属-老人绑定关系管理（支持一个老人绑定多个家属）
- FR-13-3：医生管辖社区配置（管理员分配）
- FR-13-4：数据访问隔离（家属只能看绑定的老人，医生只能看辖区老人）

## 四、非功能需求

### 4.1 易用性（老年友好）

| 需求 | 指标 |
|------|------|
| 字体可读性 | 老年端最小字体24px，默认32px |
| 触控区域 | 所有可点击元素最小48×48dp |
| 颜色对比度 | ≥7:1（WCAG AAA级） |
| 语音引导覆盖率 | 所有核心操作步骤均有TTS播报 |
| 操作层级 | 任何功能最多3步操作完成 |
| 错误恢复 | 误操作后有明显"撤销/返回"提示 |

### 4.2 性能需求

| 指标 | 目标值 |
|------|--------|
| API响应时间（P95） | ≤500ms |
| AI分析总耗时（P95） | ≤30s |
| 并发用户数 | ≥100 |
| 系统可用性 | ≥99.5% |
| 小程序冷启动（进入首页） | ≤3s |
| 文件上传速度 | ≥5MB/s |

### 4.3 安全与隐私

| 需求 | 实现方式 |
|------|----------|
| 数据传输加密 | 全程HTTPS（TLS 1.3） |
| 手机号存储 | AES-256加密 |
| 生物特征存储 | 特征向量加密，不存原始图片 |
| 访问控制 | JWT + RBAC双层控制 |
| 数据删除权 | 支持用户申请完全删除个人数据 |

### 4.4 兼容性

| 平台 | 版本要求 |
|------|----------|
| 微信（Android） | Android 9.0+，微信 8.0+ |
| 微信（iOS） | iOS 14.0+，微信 8.0+ |
| Web管理端 | Chrome 90+, Edge 90+, Firefox 88+ |
| 服务器OS | Ubuntu 22.04 LTS / CentOS 8 |

## 五、业务流程图

### 5.1 老年用户评估主流程

```
老人打开微信小程序
    ↓
人脸/声纹/手机号 登录
    ↓
首页：我的健康状况（显示上次评估摘要）
    ↓
"开始今日评估" 按钮
    ↓
系统语音引导："您好，现在开始一次简单的记忆测试，大约需要5分钟。请放松..."
    ↓
[评估流程]
    语音任务 → 量表题目 → 手写/绘图 → 行为自动记录
    ↓
"评估完成！正在分析，请稍等约20秒"
    ↓
[AI分析完成后]
    ↓
简化结果展示：
    "您的记忆力：一般"（配对应颜色图标）
    "建议：每天做10分钟词语游戏练习"
    ↓
可选：查看详细报告 / 开始推荐训练
```

### 5.2 高危预警响应流程

```
AI分析完成
    ↓
risk_level = "high" or "very_high"
    ↓
系统自动触发：
    1. 小程序内通知（订阅消息） → 老年用户："建议您近期去社区医院进行详细检查"
    2. 微信订阅消息 → 绑定家属（notify_level≥1）："李奶奶的认知评估结果需要关注"
    3. 站内通知 → 负责医生（Web端）：预警列表新增一条记录
    ↓
医生查看预警，可操作：
    - 安排上门随访
    - 制定干预计划
    - 联系家属沟通
    - 转介专科就诊
```

## 六、术语表

| 术语 | 解释 |
|------|------|
| MCI | 轻度认知障碍（Mild Cognitive Impairment），介于正常衰老和AD之间的认知衰退阶段 |
| AD | 阿尔茨海默病（Alzheimer's Disease），最常见的痴呆类型 |
| MMSE | 简易精神状态检查量表（Mini-Mental State Examination），最广泛使用的认知筛查工具，满分30分 |
| MoCA | 蒙特利尔认知评估量表（Montreal Cognitive Assessment），比MMSE更敏感，满分30分 |
| CDT | 时钟绘图测试（Clock Drawing Test），视空间和执行功能的快速筛查工具 |
| IRT | 项目反应理论（Item Response Theory），用于自适应题目难度选择 |
| CAT | 计算机自适应测试（Computer Adaptive Testing），基于IRT的动态选题策略 |
| SHAP | SHapley Additive exPlanations，AI模型可解释性方法 |
| TTS | 文字转语音（Text-to-Speech），语音引导技术 |
| STT | 语音转文字（Speech-to-Text），语音识别技术 |
