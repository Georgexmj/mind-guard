# 参赛总文件夹说明

本目录按照《4C2026 软件应用与开发参赛作品提交要求》整理，用于后续提交中国大学生计算机设计大赛“软件应用与开发类”作品材料。

当前项目名称：基于多模态交互的社区老年认知障碍早期筛查与干预系统  
作品简称：MindGuard / 忆守心安  
类别：软件应用与开发类  
当前状态：竞赛原型与演示材料整理阶段

## 目录结构

```text
参赛总文件夹
├── 01作品与答辩材料
├── 02素材与源码
├── 03设计与开发文档
└── 04作品演示视频
```

正式提交前，建议按大赛系统分配的作品编号重命名为：

```text
作品编号-参赛总文件夹
├── 作品编号-01作品与答辩材料
├── 作品编号-02素材与源码
├── 作品编号-03设计与开发文档
└── 作品编号-04作品演示视频
```

## 提交要求摘录

| 分类 | 需要准备的材料 |
| --- | --- |
| 作品与答辩材料 | 安装包、运行网址或二维码；现场答辩 PPT；PPT 转 PDF；答辩视频 |
| 素材与源码 | 团队开发源码；代表性素材；超过 10 个文件需压缩并按“作品编号-素材源码”命名 |
| 设计与开发文档 | 作品信息概要表 PDF；软件应用与开发类作品设计和开发文档 PDF；如使用 AI，提交 AI 工具使用说明 PDF 及佐证附件 |
| 作品演示视频 | 作品运行演示视频文件 |

## 重要限制

- 答辩视频：MP4，时长不超过 10 分钟，建议不高于全高清，体积不超过 500MB。
- 素材与源码总体不超过 1GB，建议控制在 500MB 以内。
- 四个文件夹中的文件只能出现一次，不得重复提交。
- 每个存放文档的文件夹下已创建 `readme.txt`，正式提交前需要根据最终文件名再核对一次。

## 当前建议提交策略

| 材料 | 建议来源 |
| --- | --- |
| Web 管理端演示 | `web-admin/` 构建产物或线上 `admin` 域名 |
| 小程序演示 | 微信开发者工具预览码或正式小程序码 |
| 后端接口演示 | `/docs` Swagger 截图或录屏 |
| 源码 | 打包 `backend/`、`web-admin/`、`miniprogram/`、`data/`、`nginx/`、`docker-compose.yml`、`.env.example`、`README.md`、`QUICKSTART.md` |
| 设计开发文档 | 参考 `03设计与开发文档` 中草稿，并结合 `docs/需求`、`docs/系统架构`、`docs/接口`、`docs/人工智能` 完善 |
