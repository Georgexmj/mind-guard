# 作品演示视频脚本

建议时长：5-8 分钟。重点展示系统真实运行效果。

## 0:00-0:20 开场

展示项目名称和一句话介绍：MindGuard 是面向社区老年人的认知障碍早期筛查与干预系统。

## 0:20-1:00 启动与访问

展示 Docker Compose 启动后的服务：

- Web 管理端。
- 后端 Swagger。
- 小程序预览。

可简要展示 `docker compose ps` 或浏览器访问页面。

## 1:00-2:30 老人端评估流程

1. 打开微信开发者工具或小程序预览。
2. 使用老人账号登录。
3. 进入首页，点击开始认知评估。
4. 展示评估说明。
5. 完成一道选择题。
6. 展示语音任务录音或上传流程。
7. 展示时钟绘制任务。
8. 提交评估。

## 2:30-3:20 结果与干预

1. 展示评估结果页。
2. 说明风险等级、领域得分和建议。
3. 进入 Top5 干预训练。
4. 完成一次打卡。

## 3:20-5:20 医生端管理流程

1. 切换 Web 管理端，使用医生账号登录。
2. 展示仪表盘统计、风险分布和高风险列表。
3. 进入老人列表和老人详情。
4. 打开评估详情，展示雷达图、结果和报告。
5. 创建或查看干预计划。
6. 展示依从性预警工单。

## 5:20-6:20 管理员与题库

1. 使用管理员账号或切换管理员视角。
2. 展示题库管理。
3. 展示 RAG 知识库或通知中心。

## 6:20-7:00 技术亮点收尾

简要说明：

- 后端异步 AI 分析。
- 规则、深度、混合模型策略。
- 评估、报告、干预、预警、复评闭环。
- 支持 Docker 部署和后续社区试点扩展。
