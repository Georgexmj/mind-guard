## 各模块命名规范

### 后端（Python/FastAPI）
- 文件名：小写下划线（`auth_service.py`）
- 类名：大驼峰（`AssessmentService`）
- 函数名：小写下划线（`get_assessment_result`）
- API路径：小写连字符（`/api/v1/assessment-sessions`）

### 前端（React/TypeScript）
- 组件文件：大驼峰（`CognitiveRadar.tsx`）
- 工具文件：小写驼峰（`authService.ts`）
- 样式文件：与组件同名（`CognitiveRadar.module.css`）

### 微信小程序（UniApp/Vue）
- 文件名：小写连字符（`voice-task.vue`，页面）或小写连字符（`voice-recorder.vue`，组件）
- 组件名（Vue SFC）：大驼峰导出（`export default { name: 'VoiceRecorder' }`）
- store文件：小写（`assessment.js`）
- 工具文件：小写驼峰（`request.js`、`tts.js`）
- 页面目录：与路由路径一致（`pages/assessment/voice-task.vue`）
