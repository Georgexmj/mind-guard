# 答辩 PPT 大纲

建议控制在 12-16 页，现场答辩 6-8 分钟，预留评委提问时间。

## 1. 封面

- 项目名称：基于多模态交互的社区老年认知障碍早期筛查与干预系统
- 作品简称：MindGuard / 忆守心安
- 参赛类别：软件应用与开发类
- 团队、学校、指导教师、日期

## 2. 项目背景与痛点

- 老龄化背景下认知障碍早筛需求增长。
- 社区医生资源有限，传统量表依赖面对面施测。
- 老年人数字化产品使用门槛高，持续干预依从性不足。

## 3. 项目目标

- 面向社区场景提供低门槛、可持续的认知风险筛查工具。
- 将老人、家属、医生、管理员纳入同一协同闭环。
- 用 AI 辅助评估、解释和干预推荐，提升筛查与随访效率。

## 4. 系统总体方案

- 老人端微信小程序：评估、语音/绘图任务、结果查看、干预打卡。
- 医生/管理员 Web 端：老人档案、评估报告、干预计划、预警工单。
- 后端服务：认证、评估、AI 分析、报告、通知、RAG 知识库。
- Docker 部署：MySQL、Redis、MinIO、Celery、Nginx。

## 5. 核心业务流程

```text
老人完成评估 -> 后端收集作答 -> Celery 异步分析 -> 生成评估结果
-> 医生查看报告 -> 制定干预计划 -> 老人打卡 -> 依从性预警 -> 复评提醒
```

## 6. 多模态评估设计

- 量表题：记忆、定向、语言、注意、视空间、执行功能。
- 语音任务：记录语音文件与作答文本。
- 绘图任务：时钟绘制任务，为后续视觉/笔迹特征扩展留接口。
- 行为特征：反应时间、完成情况、历史趋势。

## 7. AI 分析方案

- `rule`：规则模型，保证稳定可解释。
- `deep`：深度多模态融合模型，读取训练 checkpoint。
- `hybrid`：规则 + 深度模型融合，当前推荐演示策略。
- 输出：风险等级、NC/MCI/AD 概率、MMSE 等效分、六领域得分、解释字段。

## 8. 技术架构

- 后端：FastAPI + SQLAlchemy + Celery + Redis。
- 前端：React + TypeScript + Ant Design + ECharts。
- 小程序：UniApp + Vue 3 + Pinia。
- 存储：MySQL、MinIO，预留 InfluxDB 和 MongoDB。
- 部署：Docker Compose + Nginx。

## 9. 功能演示一：老人端

- 登录。
- 开始评估。
- 完成选择题、语音题、绘图题。
- 查看评估结果。
- 查看 Top5 干预训练并打卡。

## 10. 功能演示二：医生/管理员端

- 登录 Web 管理端。
- 查看仪表盘统计和风险分布。
- 查看老人列表和评估详情。
- 导出医生 PDF/家庭可读报告。
- 创建干预计划，处理依从性工单。

## 11. 创新点

- 社区场景的多角色协同闭环。
- 老年友好小程序降低使用门槛。
- 评估与干预闭环联动，不停留在单次问卷。
- 规则与深度模型混合策略，兼顾稳定性和扩展性。
- RAG 知识库支持干预建议与解释材料扩展。

## 12. 工程完成度

- 后端、Web、小程序、Docker 部署均已具备。
- 关键接口已形成闭环。
- 文档体系已包含需求、架构、接口、部署、算法、商业计划。

## 13. 应用价值

- 提升社区老年认知筛查覆盖率。
- 帮助医生从“被动接诊”转向“主动预警和干预”。
- 帮助家属理解风险并参与日常陪伴与监督。
