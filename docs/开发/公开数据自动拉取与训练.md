# 公开多模态数据自动拉取与训练

## 1. 目标
提供一条可直接执行的工程链路：

1. 从公开网络源自动拉取音频、图片、视频样本。
2. 自动构建 `train_deep_multimodal.py` 所需的训练 CSV。
3. 一键触发深度多模态模型训练（或先只生成 CSV）。

对应脚本：

- `backend/scripts/bootstrap_open_multimodal.py`

## 2. 快速使用

在项目 `backend` 目录执行：

```bash
python -m scripts.bootstrap_open_multimodal --skip-train
```

完整训练（当前 Python 环境需已安装 `torch`）：

```bash
python -m scripts.bootstrap_open_multimodal \
  --samples 180 \
  --epochs 20 \
  --batch-size 64 \
  --lr 1e-3 \
  --output-csv ../data/deep_train_auto.csv \
  --checkpoint models/deep_multimodal_fusion.pt
```

## 3. 默认数据来源

脚本默认从以下公开仓库自动抽样下载：

1. 音频（wav）：Free Spoken Digit Dataset（GitHub）
2. 图片/视频：OpenCV sample data（GitHub）

## 4. 输出产物

默认产物位置：

1. 原始文件目录：`data/open_multimodal_seed/raw/`
2. 训练 CSV：`data/deep_train_auto.csv`
3. 运行清单：`data/deep_train_auto_manifest.json`
4. 模型权重（训练成功时）：`backend/models/deep_multimodal_fusion.pt`

## 5. 参数说明

常用参数：

1. `--samples`：生成训练样本数（最小会被提升到 32）
2. `--audio-count`：下载音频数量
3. `--image-count`：下载图片数量
4. `--video-count`：下载视频数量
5. `--skip-train`：只生成 CSV，不执行训练

## 6. 与项目当前模态的对应关系

脚本会按项目现有输入格式生成这些特征列：

1. `questionnaire_*`
2. `voice_*`
3. `drawing_*`
4. `behavior_*`
5. `target_class`
6. `target_domain_*`

因此可直接喂给：

- `backend/scripts/train_deep_multimodal.py`

## 7. 重要边界

1. 当前脚本用于“工程通路打通”和“自动化训练验证”，不是临床标注级数据集。
2. ADReSS / ADReSSo / DAIC-WOZ / DementiaBank 等授权数据集通常需要账号与协议，不可匿名自动下载。
3. 若本机环境缺少 `torch`，脚本会保留下载与 CSV 产物，并提示训练跳过。
