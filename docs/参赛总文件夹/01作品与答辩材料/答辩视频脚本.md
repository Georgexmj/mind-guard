# 答辩视频脚本

要求：MP4，时长不超过 10 分钟，建议控制在 8 分钟左右。

## 0:00-0:40 开场

大家好，我们的作品是《基于多模态交互的社区老年认知障碍早期筛查与干预系统》，简称 MindGuard。项目面向社区老年群体，目标是通过微信小程序和医生管理端，完成认知风险早筛、AI 辅助分析、报告生成、干预计划与依从性预警。

## 0:40-1:40 背景痛点

当前社区认知障碍早筛面临三个问题：第一，传统量表依赖专业人员面对面施测，社区覆盖率不足；第二，老年人使用复杂 App 的门槛较高；第三，很多系统只完成一次测评，没有形成后续干预和复评闭环。

## 1:40-2:40 方案概述

我们的系统分为三部分：老人端微信小程序、医生和管理员 Web 管理端、FastAPI 后端服务。老人通过小程序完成评估和干预打卡；医生在 Web 端查看报告、创建计划、处理预警；后端完成认证、评估、AI 分析、通知、RAG 知识检索和异步任务调度。

## 2:40-4:00 老人端演示

演示老人账号登录。进入首页后点击开始认知评估，系统展示评估说明。随后依次完成认知题目、语音任务和时钟绘制任务。提交后系统触发异步分析，完成后可查看风险等级、领域得分和通俗化建议。老人还可以进入干预训练页面，查看推荐训练并完成每日打卡。

## 4:00-5:40 医生端演示

切换到医生账号登录 Web 管理端。首页展示社区老人总数、评估数量、风险分布和高风险列表。进入老人详情可查看历史评估、六维认知雷达图和评估趋势。医生可以根据结果创建干预计划，并在依从性工单中处理老人漏打卡或中断训练的预警。

## 5:40-6:40 技术架构

系统后端采用 FastAPI、SQLAlchemy 和 Celery，使用 MySQL 存储业务数据，Redis 作为异步任务队列，MinIO 用于文件存储。Web 管理端使用 React、Ant Design 和 ECharts；小程序使用 UniApp 和 Vue 3。部署层使用 Docker Compose 和 Nginx。

## 6:40-7:40 AI 与创新点

AI 分析支持三种策略：规则模型、深度模型和混合模型。规则模型保证演示稳定，深度模型用于融合量表、语音、绘图和行为特征，混合策略兼顾稳定性和扩展性。系统创新点在于把筛查、解释、干预、打卡、预警和复评连接为完整闭环，并面向老人端做了大字体、低层级和微信生态适配。

## 7:40-8:30 总结

MindGuard 希望帮助社区医生更早发现认知风险，帮助家属理解老人状态，帮助老人以低门槛方式参与筛查和日常训练。后续我们将继续完善真实数据验证、模型评估、小程序上线和社区试点。
