## 作品名称

基于多模态交互的社区老年认知障碍早期筛查与干预系统

## 作品简称

MindGuard / 忆守心安

## 作品类别

软件应用与开发类

## 作品简介

本作品面向社区老年人认知障碍早期筛查与干预场景，构建了老人端微信小程序、医生/管理员 Web 管理端和后端 AI 分析服务。老人可通过小程序完成认知评估、语音任务、绘图任务和干预打卡；社区医生可在 Web 管理端查看评估报告、风险趋势、干预计划和依从性预警；系统后端基于 FastAPI、Celery 和多模态 AI 分析策略，实现评估、报告、干预、提醒与复评的闭环管理。

## 解决的问题

1. 社区认知障碍早筛覆盖率不足，传统评估依赖专业人员面对面施测。
2. 老年人使用复杂数字产品门槛较高，普通 App 依从性不足。
3. 单次筛查难以形成持续干预与复评机制。
4. 社区医生缺少统一工具查看群体风险、重点老人和干预执行情况。

## 主要功能

- 老人、家属、医生、管理员四类角色与权限管理。
- 微信小程序老人端登录、评估作答、语音上传、时钟绘制、结果查看、干预打卡。
- Web 管理端仪表盘、老人档案、评估详情、题库管理、干预计划、通知中心。
- AI 分析支持规则、深度模型和混合策略。
- 医生 PDF 报告、家庭可读报告、评估趋势与风险分布。
- 干预 Top5 推荐、打卡记录、依从性预警工单和提醒分发。
- RAG 知识库支持干预建议和解释材料扩展。

## 技术路线

- 后端：Python 3.11、FastAPI、SQLAlchemy、Pydantic、Celery、Redis。
- 前端：React 18、TypeScript、Vite、Ant Design、ECharts、Zustand。
- 小程序：UniApp、Vue 3、Pinia、微信录音和 Canvas 能力。
- AI：规则模型、PyTorch 深度多模态模型、混合推理策略。
- 存储：MySQL、Redis、MinIO，预留 InfluxDB 和 MongoDB。
- 部署：Docker Compose、Nginx。

## 创新点

1. 面向社区老年人构建从早筛到干预的完整闭环。
2. 微信小程序适老化交互，降低老人使用门槛。
3. 融合量表、语音、绘图、行为等多模态信息，提升评估维度。
4. 规则与深度模型混合策略，兼顾稳定性和技术扩展性。
5. 医生端依从性预警工单，将干预执行情况转化为可处理任务。
