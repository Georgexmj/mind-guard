# API 接口设计文档

**项目：** 基于多模态交互的社区老年认知障碍早期筛查与干预系统
**基础URL：** `https://api.cognitive-screen.com/api/v1`
**认证方式：** Bearer Token（JWT）
**内容类型：** `application/json`
**版本：** v1.0 | 2026-03

---

## 通用规范

### 请求头
```
Authorization: Bearer <access_token>
Content-Type: application/json
Accept: application/json
```

### 统一响应格式
```json
// 成功
{
  "code": 200,
  "message": "success",
  "data": { ... }
}

// 失败
{
  "code": 400,
  "message": "具体错误描述",
  "data": null
}
```

### 错误码
| 错误码 | 含义 |
|--------|------|
| 200 | 成功 |
| 201 | 创建成功 |
| 202 | 异步任务已接受 |
| 400 | 请求参数错误 |
| 401 | 未认证（Token无效/过期） |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 422 | 数据验证失败 |
| 500 | 服务器内部错误 |

## 一、认证接口（/auth）

### POST /auth/login/phone
**手机号+验证码登录**

请求：
```json
{
  "phone": "13812345678",
  "sms_code": "123456"
}
```

响应：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "access_token": "eyJhbGci...",
    "refresh_token": "eyJhbGci...",
    "token_type": "Bearer",
    "expires_in": 7200,
    "user": {
      "id": 1,
      "uuid": "a1b2c3d4-...",
      "name": "张大爷",
      "role": "elder"
    }
  }
}
```

---

### POST /auth/login/face
**人脸识别登录（老年用户首选）**

请求：`multipart/form-data`
- `face_image`: 人脸照片（JPEG/PNG，最大2MB）

响应：同上

---

### POST /auth/refresh
**刷新Access Token**

请求：
```json
{
  "refresh_token": "eyJhbGci..."
}
```

响应：
```json
{
  "code": 200,
  "data": {
    "access_token": "eyJhbGci...",
    "expires_in": 7200
  }
}
```

---

### POST /auth/send-sms
**发送短信验证码**

请求：
```json
{
  "phone": "13812345678"
}
```

---

### POST /auth/logout
**登出（使Token失效）**

响应：`{"code": 200, "message": "已退出登录"}`

## 四、多模态数据接口（/modality）

### POST /modality/voice/upload
**上传语音文件**

请求：`multipart/form-data`
- `session_id`: 评估会话ID
- `task_name`: 任务名称（如`picture_description`）
- `audio_file`: 音频文件（WAV/M4A，最大50MB）

## 附录：数据字典

### 风险等级（risk_level）
| 值 | 说明 | 建议操作 |
|----|------|----------|
| `low` | 低风险（P < 0.25） | 6个月后复查 |
| `medium` | 中风险（0.25 ≤ P < 0.50） | 3个月后复查 + 开始预防性干预 |
| `high` | 高风险（0.50 ≤ P < 0.75） | 1个月内专科就诊 + 强化干预 |
| `very_high` | 极高风险（P ≥ 0.75） | 立即就医 + 家属通知 |

### 分类结果（classification）
| 值 | 说明 |
|----|------|
| `NC` | 认知正常（Normal Cognition） |
| `MCI` | 轻度认知障碍（Mild Cognitive Impairment） |
| `mild_AD` | 轻度阿尔茨海默病（Mild Alzheimer's Disease） |
| `uncertain` | 数据质量不足，结果不确定 |
