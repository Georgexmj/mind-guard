# 演示录制检查清单

## 录制前

- [ ] 后端服务可访问 `/health`。
- [ ] Web 管理端可登录。
- [ ] 小程序可登录老人账号。
- [ ] Celery worker 正常运行。
- [ ] 演示账号密码正确。
- [ ] 浏览器缩放比例合适。
- [ ] 桌面无无关窗口、隐私信息、聊天通知。
- [ ] 麦克风声音清晰。
- [ ] 录屏分辨率不高于全高清，便于压缩。

## 录制中

- [ ] 展示项目名称和系统用途。
- [ ] 展示老人端评估流程。
- [ ] 展示医生端报告和干预流程。
- [ ] 展示至少一个 AI 分析结果。
- [ ] 展示干预打卡或依从性预警。
- [ ] 不展示真实密钥、证书私钥、真实身份证号。

## 录制后

- [ ] 视频格式为 MP4。
- [ ] 声音稳定，无长时间静音。
- [ ] 画面清晰，文字可读。
- [ ] 时长符合比赛要求。
- [ ] 体积小于 500MB。
- [ ] 文件名替换为正式作品编号。
- [ ] 答辩视频和作品演示视频没有重复放入两个文件夹。
